# 로컬 채팅 대시보드

화면은 검은색(`#000000`) 배경에 입력창과 채팅 패널 제목 영역만 짙은 파랑으로
구성했습니다. 참고 이미지 `assets/hq720.avif`의 흰색 픽셀 글자 분위기를 유지하며,
글꼴은 [Neo둥근모](https://github.com/neodgm/neodgm)(OFL-1.1)을
사용하며, 로컬 설치된 글꼴이 없다면 jsDelivr에서 불러옵니다. 웹폰트 로딩에는
인터넷 연결이 필요하고, 로딩 실패 시 시스템 글꼴을 사용합니다.
글자는 픽셀 형태를 유지하도록 기본 16px, 제목 32px로 표시합니다.
기본 테마는 다크모드이며 상단 버튼으로 라이트모드와 전환할 수 있습니다.
선택한 테마는 브라우저에 저장되어 새로고침 후에도 유지됩니다.

Node.js 기본 모듈과 Python/pytchat만 사용합니다. npm 설치는 필요 없습니다.
기존 main.py는 그대로 두고, 대시보드 전용 chat_bridge.py를 연결했습니다.

1. 프로젝트 폴더에서 `node server.js`를 실행합니다.
2. 브라우저에서 http://127.0.0.1:3000 을 엽니다.
3. 방송 URL 또는 영상 ID를 입력하고 **감시 시작**을 누릅니다.

대시보드는 Node.js를 실행한 로컬 주소에서 사용하세요.

서버는 이 컴퓨터의 127.0.0.1:3000에만 연결됩니다. Python은 프로젝트의
`.venv` 안의 Python만 사용합니다. Windows에서는 `.venv\Scripts\python.exe`,
그 외에는 `.venv/bin/python`을 실행합니다. `PYTHON` 환경 변수와 PATH의 일반
Python은 사용하지 않습니다. 실행 파일이 없으면 감시을 시작하지 않고 오류를 표시합니다.
pytchat이 없다면 `.venv` 안의 Python으로 `-m pip install pytchat`을 실행하세요.

프로필 사진은 `author.imageUrl`, 커스텀 이모티콘은 `messageEx`의 이미지 URL로
표시합니다. 이미지를 가져오려면 인터넷 연결이 필요합니다.

채팅은 `data/<영상 ID>/chats.jsonl`에 한 줄에 한 건씩 자동 저장합니다.
예를 들어 `https://www.youtube.com/watch?v=VYhnTDAmZDM`은
`data/VYhnTDAmZDM/chats.jsonl`에 저장됩니다. URL 형식이 달라도 영상 ID가 같으면
동일한 폴더를 사용합니다. Windows 폴더 이름으로 사용할 수 없는 URL의 기호 대신
영상 ID로 폴더를 구분합니다.

같은 영상으로 감시을 시작하면 기존 기록을 먼저 불러오고 새 채팅을 이어서 저장합니다.
채팅 ID가 같은 항목은 다시 저장하지 않습니다. 슈퍼챗 목록은 같은 파일에서
슈퍼챗만 골라 복원하므로 별도 파일을 관리할 필요가 없습니다.
새로고침하거나 연결이 복구되면 서버에서 현재 영상의 기록을 다시 받습니다.
서버를 재시작한 경우에는 해당 URL을 입력하고 감시 시작을 누르면 기록을 불러옵니다.
인터넷 연결이나 Python 실행이 실패해도 불러온 기록은 확인할 수 있습니다.

감시한 전체 기록을 파일에 보관하고 화면에서도 개수 제한 없이 표시합니다.
감시 개수는 저장된 전체 기록 기준입니다. 프로필과 이모티콘은 이미지 URL만 저장합니다.

각 슈퍼챗 오른쪽 위의 **읽음**을 체크하면 흐리게 표시됩니다. 체크를 해제하면
다시 안 읽은 상태가 됩니다. 상태는 영상별 `read.json`에 별도로 저장되며,
새로고침하거나 같은 영상을 다시 불러와도 복원됩니다.
**안 읽은 슈퍼챗만 보기**로 읽은 항목을 숨기고, **전체 슈퍼챗 보기**로 다시 표시합니다.
필터는 슈퍼챗 목록에만 적용되며 채팅 기록을 삭제하지 않습니다.

**슈퍼챗 내보내기**를 누르면 현재 영상의 전체 슈퍼챗을 CSV로 다운로드합니다.
검색·읽음 필터와 관계없이 버튼을 누른 시점의 전체 기록과 읽음 상태를 포함하며,
영상 ID, 시간, 닉네임, 통화 기호가 포함된 금액, 메시지, 읽음 여부, 채팅 ID를 저장합니다.
파일명에는 영상 ID와 내보낸 시각(UTC)이 포함됩니다. 한글을 위해 UTF-8 BOM을 넣고,
메시지의 쉼표·따옴표·줄바꿈을 보존합니다. 슈퍼챗이 없으면 버튼은 비활성화됩니다.
모든 브라우저에서 일반 다운로드 방식을 사용하며, 저장 위치와 파일명 선택 창은
브라우저의 다운로드 설정에 따릅니다. CSV 생성은 브라우저에서 처리합니다.

슈퍼챗 버튼 아래에서 **시간 순으로 정렬 / 금액 순으로 정렬**을 선택하고,
**오름차순 / 내림차순** 버튼으로 방향을 바꿀 수 있습니다. 기본은 시간 오름차순입니다.
새 슈퍼챗도 선택된 순서에 맞춰 들어가며, 내보낸 CSV도 같은 순서를 사용합니다.
금액은 환율 환산 없이 각 통화의 원래 숫자로 비교합니다. 기존 기록은 표시된
금액·시간 문자열을 사용하며, 새 기록에는 숫자 금액과 타임스탬프도 함께 저장합니다.
값을 확인할 수 없는 항목은 정렬 방향과 관계없이 마지막에 표시합니다.

상단 검색창 왼쪽의 **내용 / 버섯이끼** 버튼으로 검색 대상을 선택합니다.
**내용**은 채팅 내용만, **버섯이끼**은 작성자 이름만 검색합니다.
키워드를 입력한 후 돋보기를 누르면 일치하는 채팅과 슈퍼챗만 표시하고,
돋보기를 다시 누르면 검색 필터가 해제됩니다.
필터가 켜진 동안 키워드를 수정하면 즉시 반영되며, 새로 감시되거나 복원된 기록에도
적용됩니다. 슈퍼챗의 읽음 필터와 함께 사용할 수 있고, 감시과 저장은 계속됩니다.
**버섯이끼** 모드에서 이름을 입력하면 현재 영상에서 감시한 닉네임 중 일치하는 후보를 이름순으로
표시합니다. 클릭하거나 위·아래 방향키와 Enter로 선택하고, Esc로 닫을 수 있습니다.
후보 선택은 입력을 완성하며, 돋보기로 필터를 켜거나 끕니다.
슈퍼스티커는 이번 프로토타입에 포함하지 않습니다.
감시 중지는 화면의 **중지**, 서버 종료는 터미널의 **Ctrl+C**를 사용하세요.
